# Prueba SIATA - EAFIT (Frontend)

Se encuentra desplegado en: https://prueba-siata-front.vercel.app/


## Requisitos previos

- **Node.js** (versión 18 o superior recomendada)
- **npm**

## Instalación

Clona el repositorio (o descarga el código) y luego, desde la carpeta `frontend`:

```bash
npm install
```

## Variables de entorno

Estas serán compartidas via correo. Añadirlas a la raiz del proyecto

## Ejecución en modo desarrollo

Desde la carpeta `frontend`:

```bash
npm run dev
```

Luego abre en el navegador la URL que indique Vite (normalmente `http://localhost:5173`).
